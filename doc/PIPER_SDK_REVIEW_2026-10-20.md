## SDK 版本与限位

- 下载目录版本：0.7.0a1；实际 Python 环境安装版本：0.6.2。
- 下载目录 `piper_sdk/piper_param/piper_param_manager.py` 定义 SDK 默认软件限位：
  joint1 ±150°、joint2 0～180°、joint3 -170～0°、joint4 ±100°、joint5 ±70°、joint6 ±120°。
- 源码说明 SDK 软件限幅默认关闭，打开后会影响反馈与控制。未经确认不启用反馈限幅，以免隐藏原始负读数。

  因此不能仅因下载目录包含 V3 就切换协议。

## 查询帧错误更正

之前限位查询没有返回，是本次诊断脚本使用 `can.Message()` 的默认扩展帧所致。
官方 `C_STD_CAN.SendCanMessage` 默认 `is_extended_id=False`，实际使用标准帧。
此前“没有查询响应”的结论应以本次标准帧查询为准，不应据此判断控制器不支持查询。

本次发送七条标准帧读取请求：一条 0x4AF 固件查询，六条 0x472 角度/速度限位查询。
没有发送电机使能、运动、模式切换、限位设置或零点设置指令。

## 控制器实际回复

软件固件：**S-V1.8-2**；原始版本响应同时包含硬件标识 H-V1.2-1。
以下角度从 0x473 回复按官方 0.1° 单位解码：

| 关节 | 控制器角度范围 | 当前 URDF 范围（约） |
|---|---|---|
| joint1 | -150～150° | -150～150° |
| joint2 | 0～180° | 0～179.91° |
| joint3 | -170～0° | -170～0° |
| joint4 | -100～100° | -99.98～99.98° |
| joint5 | -70～70° | -69.90～69.90° |
| joint6 | -180～180° | -120～120° |

六轴回复的最大速度原始字段均为 200。后续核对下载目录的 0.7.0a1 CHANGELOG 后更正：
该字段在 V1.5-8 及以后单位为 0.01 rad/s，当前 S-V1.8-2 应解读为 2.0 rad/s；
更旧固件才使用 0.001 rad/s。此前记录将其解释为 0.2 rad/s 不正确。
本项目当前软件指令变化率仍独立限制为 0.2 rad/s，未修改控制器参数；这不是物理运动实测结果。
URDF 对 joint6 更保守，本次未放宽。

控制器配置的 joint2 下限同样为 0°。因此此前约 -1.6° 的示教反馈不能归因于
URDF 独有的限位设置；仍需核对示教模式下反馈与限位执行的关系、零点和实际机械边界。
当前资料不足以认定零点错误，也不足以允许自动回零或放宽控制范围。
